Available M365 Copilot Declarative Agent
Agent Steward

A declarative agent for Microsoft 365 Copilot that helps IT admins discover, analyse, and govern Copilot agents across their tenant. Connects live to the Graph Package Management API and cross-references usage reports to surface duplicate agents, fragmented deployments, and org-wide consolidation opportunities.

What it does
List and classify all agents in the tenant catalog by build type
Cross-reference catalog with usage reports from the M365 admin centre
Detect active duplicates, orphaned agents, and fragmented deployments
Identify org-wide promotion candidates and recommend consolidation actions
Sample prompts
Top 20 Agent Builder agents Find duplicates across my tenant Org-wide consolidation candidates Agents with zero usage

Available Power Platform Custom Connector
Copilot Agent Catalog

A Power Platform custom connector for the Microsoft Graph Copilot Admin Catalog API. Import the included swagger file to use the connector in Power Automate flows, Power Apps, and Logic Apps — no API integration code required.

What it does
List and filter all Copilot agent packages in the tenant with OData support
Retrieve full metadata for a specific agent by ID
Drive inventory sync, governance flows, and Power BI reporting with no code
Import the included swagger file directly into Power Platform custom connectors
